# 📡 Splius Digital Transformation Sketch

Interaktyvus vizualinis eskizas, skirtas tyrinėti galimą **Splius kompanijos atnaujinimą internetinėje erdvėje**.

🔗 Demo: [https://mbitc.github.io/splius-rebranding-sketch/](https://mbitc.github.io/splius-rebranding-sketch/)

---

## 🧠 Idėja

Šis projektas nėra tik dizaino eksperimentas — tai **skaitmeninės transformacijos koncepcija**, apimanti:

* vartotojo patirties pergalvojimą
* paslaugų pateikimo struktūrą
* skaitmeninės infrastruktūros kryptį
* sąveiką tarp vartotojo ir sistemos

Eskizas modeliuoja, kaip Splius galėtų veikti kaip **moderni, skaitmeniškai orientuota platforma**, o ne tik tradicinis paslaugų teikėjas.

---

## 🎯 Tikslai

* Perorganizuoti skaitmeninę erdvę (web kaip platforma, ne puslapis)
* Supaprastinti vartotojo kelią (UX)
* Sukurti aiškią informacijos architektūrą
* Paruošti pagrindą tolimesnei technologinei evoliucijai

---

## 🧩 Kas čia yra

Projektas apima:

* Interaktyvų UI eskizą (HTML / CSS / JS)
* Platforminio tipo layout struktūrą
* Paslaugų pateikimo modelius
* Navigacijos ir vartotojo srautų variantus

---

## 🌐 Plėtros kryptys

### 🔗 Web3 integracija

Galimos kryptys:

* Decentralizuotas vartotojo identitetas (wallet-based auth)
* Paslaugų valdymas per smart contract logiką
* NFT kaip prieigos / abonemento modelis
* IPFS pagrindu veikiantis turinio sluoksnis
* Vartotojo duomenų kontrolė (encryption + self-custody)

---

### 📱 Mobilios aplikacijos

Eskizas gali būti transformuotas į:

* React Native pagrindu veikiančias aplikacijas
* Native iOS / Android sprendimus
* Unified UX tarp web ir mobile
* Offline / low-connectivity scenarijus

---

### 🧠 Sisteminė architektūra

* Design system (tokens, komponentai, standartai)
* Headless architektūra
* API-first modelis
* Modulinių paslaugų struktūra
* Integracija su esamomis backend sistemomis
